# Déclaration d'utilisation de l'IA

Les fondations du projet (architecture, code Python et TypeScript, tests, documentation) ont été
produites avec l'assistant de programmation **Claude Code** (Anthropic), à partir d'une
spécification rédigée par l'équipe et sous sa supervision.

- Les sources agronomiques ont été lues (PDF et pages officielles) avant d'être citées ; chaque
  valeur reprise porte sa référence dans `data/reference/`. L'équipe doit relire ces valeurs.
- Les chiffres présentés sont calculés par le code à partir des données NASA ; aucun résultat
  n'a été rédigé par l'IA sans calcul.
- L'application elle-même n'utilise **aucune IA générative** : les explications sont produites
  par des règles déterministes et testées.
